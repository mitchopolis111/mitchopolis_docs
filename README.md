# Mitchopolis Docs

This repo contains operational docs, best-practice procedures, and daily logs for the Mitchopolis engineering system.

## Key Documents

- `best_practice_procedures_master.md` — canonical rules for daily flow, automation, Git standards, folder structure, and shutdown procedure.
- `best_practice_procedures_codex_cloud_v6.md` — Codex Cloud delegation rules, branch discipline, and review rules.
- `best_practices_log.md` — chronological record of procedure changes, daily notes, and next-day focus.

## How to Use This Repo

1. New day or new machine: read the Master procedures first.
2. When using Codex Cloud: follow the Codex addendum (v6).
3. End of each work session: append to the Best practices log with what changed, tests run, and next steps.

## Scope and Boundaries

- This repo is documentation only; it does not contain services or automation code.
- Detailed procedures live in the key documents above. Other folders (cheat sheets, architecture, logs) provide supporting references.

## Deeper Documentation

- `cheat_sheets/` — quick reference workflows.
- `architecture/` — system design and diagrams.
- `logs/` — phase build logs and historical notes.
